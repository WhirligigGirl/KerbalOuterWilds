# KerbalOuterWilds
A scaled up version of the solar system from Outer Wilds as a Kopernicus planet mod for Kerbal Space Program.

Requires Kopernicus (and its prerequisites), KopernicusExpansions, and Principia.

**System Layout**
* Sun: A K8IV Subgiant, just on the cusp of evolving into a red giant.
* The Hourglass Twins: Binary system of half-Earth-mass terrestrial planets.
    * Ember Twin: A planet covered in canyons and mesas. (currently Duna template)
    * Ash Twin: A ball of sand with some equatorial landmasses. (terrain done)
* Timber Hearth: Barren desert world with oasis-filled multi-ring impact basins. (terrain done)
    * The Attlerock: A brown-gray moon-like world with its backside blown to smithereens. (finished)
* Brittle Hollow: A low-density rocky planet. Terrain interpretation TBD. (currently Eve template)
    * Hollow's Lantern: A volcanic moon with a molten surface. (currently Moho template)
* Giant's Deep: A massive ocean world with swirling green clouds. (scaledspace texture done)
* Blue Loner: A pale blue ice giant. (Dark Bramble has not taken over yet. Scaledspace texture done)
* The Interloper: An interstellar comet on an eccentric retrograde orbit. (currently Minmus template)

Still in early WIP. System configuration is subject to change, which can break Principia save files.
